# Rostrum Homebrew Tap

```bash
brew install --cask hqn07/rostrum/rostrum
```

Homebrew tap for [Rostrum](https://rostrumstudy.app), a study app for the Mac: record lectures, take notes, study with an AI tutor, and review flashcards.

Already installed it as `studybar`? Run `brew update` and Homebrew moves it to the new name.
